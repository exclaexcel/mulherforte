## 1. Objetivo e limites da auditoria

O objetivo é verificar se a experiência atual:

- usa linguagem adequada para a usuária;
- possui navegação clara;
- funciona de forma coerente no celular;
- permite encontrar facilmente as principais funcionalidades;
- apresenta ações, retornos, estados vazios, sucessos e erros com clareza;
- possui um fluxo suficientemente completo para cadastrar receitas manualmente;
- está pronta para o fechamento do MVP do ponto de vista de UX.

Também deve ser avaliada, apenas como planejamento futuro, a viabilidade de:

- colar texto de receita;
- importar receita por PDF;
- usar OCR em PDFs escaneados ou imagens;
- importar treinos da Mi Band 5;
- integrar futuramente com o aplicativo usado pela pulseira ou com recursos do Android.

Essas funcionalidades futuras não devem ser tratadas automaticamente como bloqueadoras do MVP.

A auditoria não deve repetir toda a análise de banco, RLS, grants, dependências ou segurança já realizada, exceto quando um ponto tiver impacto direto na UX auditada.

Edição, exclusão, busca e filtros não devem ser classificados automaticamente como bloqueadores. Avaliar o impacto real de cada ausência.

## 8. Proposta “Colar receita”

Sem implementar, desenhar uma funcionalidade de apoio ao cadastro.

Fluxo desejado:

1. usuária escolhe “Colar receita”;
2. cola o texto completo;
3. o sistema identifica sugestões de:
   - nome;
   - categoria;
   - ingredientes;
   - modo de preparo;
   - congelamento;
   - validade;
   - notas;
4. os campos são preenchidos em uma prévia;
5. a usuária revisa todos os campos;
6. a usuária corrige o que for necessário;
7. a usuária confirma;
8. somente então a receita é salva.

Regras obrigatórias:

- nenhuma gravação automática;
- nenhum campo sugerido deve ser tratado como certeza;
- todos os campos devem continuar editáveis;
- texto original deve permanecer disponível durante a revisão;
- quebras de linha devem ser preservadas;
- a usuária pode cancelar sem salvar;
- duplicidade por nome deve ser verificada;
- a criação manual deve permanecer disponível.

Comparar as opções:

1. criação manual atual;
2. colar texto sem interpretação automática;
3. colar texto com identificação assistida;
4. importar PDF textual;
5. OCR de PDF ou imagem.

Para cada opção, informar:

- valor para a usuária;
- esforço estimado;
- dependências;
- privacidade;
- necessidade de serviço externo;
- taxa provável de erro;
- testes;
- impacto no banco;
- recomendação:
  - antes de fechar o MVP;
  - Fase 2;
  - não recomendado.

Não implementar.
